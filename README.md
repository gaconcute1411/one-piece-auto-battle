# One Piece Auto Battle

A Godot 2D pixel-art auto-battle prototype with a character roster, battle scenes, and animation assets.

## Run the project

1. Install the Godot version listed in `project.godot` (Godot 4.7).
2. In Godot Project Manager, import this folder by selecting `project.godot`.
3. Open the project and run the main scene (`scenes/title_screen.tscn`).

## Project contents

- `scenes/` — lobby, battle, training, summon, and other game screens
- `scripts/` — gameplay and UI logic
- `data/` — character and skill data
- `animations/` and `assets/` — character frames and visual assets
- `docs/` — design and integration notes

Godot's generated `.godot/` cache and the older nested project copy are excluded from version control.
